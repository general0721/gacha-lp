# 次世代医療ダイエット無料チケットガチャ LP

スマホ専用の1ページLP。画面をタップすると、取手が回り→本体が揺れ→ガラス球の中のカプセルが1個ずつ転がり→取り出し口からカプセルが出て→中央へ浮上→虹色に光って割れ→花吹雪とともにチケットが出る。

## 構成

| ファイル | 内容 |
| --- | --- |
| `index.html` | ページ本体（CSS・JavaScript を内包） |
| `assets/*.webp` | 表示に使う画像 |
| `assets/*-src.png` | 加工前の元画像（支給素材） |
| `build_assets.py` | 元画像から `*.webp` を作り直すスクリプト |
| `dist/` | 配布用（`index.html` と使用画像のみ、約600KB） |

## 公開のしかた

`dist/` の中身をそのままサーバーに置くだけ。サーバー側の設定は不要。
見出しの欧文フォントのみ Google Fonts から読み込む。

## 素材の作り直し

```
python3 build_assets.py
```

Pillow と numpy が必要。元画像を差し替えた場合は、`build_assets.py` 内の座標
（取手の中心、ガラス球の中心、カプセルの継ぎ目など）と、`index.html` のガチャの
位置・大きさ（台の天面に合わせる）を測り直す。

## メモ

- タップは1回のみ。もう一度見るには再読み込み。
- CTA の遷移先は `index.html` 内の `id="cta"` の `href`。
- チケット画像内の※注記はスマホだと約5pxで読めない。掲載前に要検討。
